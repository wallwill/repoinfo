# Examples

This directory contains example `repoinfo.yml` files for common repository shapes across older and newer enterprise stacks.

Each subdirectory represents the root of a repository. The `repoinfo.yml` file is shown where it would live in that repository.

These examples intentionally span long-lived software estates: legacy batch jobs, enterprise web applications, services, UIs, ML services, and cloud-native systems. The goal is to show that the same small file can provide useful context for humans, tools, and agents without requiring every repository to be modernized first.

## Examples included

- `c-oracle-unix-batch`
- `java-struts-webapp`
- `dotnet-webforms-iis`
- `java-springboot-api`
- `node-react-ui`
- `python-fastapi-ml-service`
- `go-kubernetes-service`
