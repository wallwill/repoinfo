# Specification

The source of truth for the `repoinfo.yml` specification is [SPEC.md](https://github.com/wallwill/repoinfo/blob/main/SPEC.md).

The JSON Schema for validation is available at [schema/repoinfo.schema.json](https://github.com/wallwill/repoinfo/blob/main/schema/repoinfo.schema.json).

`repoinfo.yml` is intentionally small: repository identity, stack, and relationships.
