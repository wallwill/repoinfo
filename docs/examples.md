# Examples

Example `repoinfo.yml` files are available in the [`/examples`](https://github.com/wallwill/repoinfo/tree/main/examples) directory.

The examples are stack-driven and span older and newer enterprise repository shapes:

- C / Oracle / Unix batch
- Java Struts webapp
- .NET WebForms on IIS
- Java Spring Boot API
- Node / React UI
- Python FastAPI ML service
- Go Kubernetes service

Each folder represents a repository root containing a `repoinfo.yml` file.
