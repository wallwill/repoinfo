# Contributing

Contribution guidelines are available in [CONTRIBUTING.md](https://github.com/wallwill/repoinfo/blob/main/CONTRIBUTING.md).

Useful starting points:

- Open an issue to discuss a spec change.
- Add a real-world example under `/examples`.
- Improve wording, links, or examples in the documentation.

Spec changes should preserve backwards compatibility.
